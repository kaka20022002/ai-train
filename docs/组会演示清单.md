# 组会演示清单（约 5–8 分钟）

## 启动前（本机）

```bash
# 后端
cd "/path/to/ai-train"
source .venv/bin/activate   # 或 .venv/bin/uvicorn ...
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 小程序
cd miniprogram
npm run build:weapp   # 或 npm run dev:weapp
```

1. 浏览器打开 http://localhost:8000/docs 确认后端正常  
2. 微信开发者工具打开 `miniprogram/`（读 dist）  
3. 勾选「不校验合法域名」  
4. 用**模拟器**编译预览（共享屏幕优先模拟器，勿用真机）  
5. 确认 `src/utils/config.ts` 中 `API_BASE = http://localhost:8000`

## 演示路径建议

| 顺序 | 页面 | 要点 |
|------|------|------|
| 1 | 今日训练 | 准备度、中文动作名、点击动作播放教程 |
| 2 | 开始训练 | 打卡一组 / 休息倒计时 |
| 3 | 我的 → 编辑档案 | 改目标/伤病并保存 |
| 4 | AI 教练 | 快捷问题或打字提问（若提示本地模式：DeepSeek 余额不足） |
| 5 | 计划 / 动作库 | 一笔带过功能完整度 |

## 常见翻车与应对

| 现象 | 处理 |
|------|------|
| 页面空白 / 连不上后端 | 确认 uvicorn 在 8000；模拟器用 localhost |
| 教练「本地模式」 | DeepSeek 充值，或演示规则回复并说明 |
| 教程无图 | 点「臀冲」等有图示动作；勾选不校验域名 |
| 真机调试失败 | 组会改用模拟器；真机需热点 + `sync-api-base.sh` |
