# 组会演示清单（约 5–8 分钟）

## 启动前（本机）

```bash
# 后端
cd "/path/to/ai-train"
source .venv/bin/activate   # 或 .venv/bin/uvicorn ...
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 小程序
cd miniprogram
npm run build:weapp   # 或 npm run dev:weapp
```

1. 浏览器打开 http://localhost:8000/docs 确认后端正常  
2. 微信开发者工具打开 `miniprogram/`（读 dist）  
3. 勾选「不校验合法域名」  
4. 用**模拟器**编译预览（共享屏幕优先模拟器，勿用真机）  
5. 确认 `src/utils/config.ts` 中 `API_BASE = http://localhost:8000`

## 演示路径建议

| 顺序 | 页面 | 要点 |
|------|------|------|
| 1 | 今日训练 | 准备度、中文动作名、点击动作播放教程 |
| 2 | 开始训练 | 打卡一组 / 休息倒计时 |
| 3 | 我的 → 编辑档案 | 改目标/伤病并保存 |
| 4 | AI 教练 | 快捷问题或打字提问（若提示本地模式：DeepSeek 余额不足） |
| 5 | 计划 / 动作库 | 一笔带过功能完整度 |

## 常见翻车与应对

| 现象 | 处理 |
|------|------|
| 页面空白 / 连不上后端 | 确认 uvicorn 在 8000；模拟器用 localhost |
| 教练「本地模式」 | DeepSeek 充值，或演示规则回复并说明 |
| 教程无图 | 点「臀冲」等有图示动作；勾选不校验域名 |
| 真机调试失败 | 组会改用模拟器；真机需热点 + `sync-api-base.sh` |

## 视频动作安全分析（可选，另预留 3–5 分钟）

1. 确认 Qwen 多模态 vLLM 端点已启动，后端 `.env` 中
   `V_SOCRATE_ENDPOINTS`、`V_SOCRATE_CLIP_MODEL` 可用。
2. 网页打开 `http://localhost:3000/video-analysis`。
3. 上传一段机位固定、能看到完整身体的短运动视频。
4. 输入：“请检查整个视频中的动作是否有明显问题，是否可能增加受伤风险？”
5. 展示两阶段结果：
   - V-Socrate 的可见动作观察、证据时间点与机位限制；
   - DeepSeek（或当前 `LLM_PROVIDER`）结合用户伤病档案给出的最终建议。

只验证页面和上传链路时可设置 `V_SOCRATE_USE_MOCK=true`，但演示时必须说明
Mock 没有真正读取视频，不能作为动作判断结果。
