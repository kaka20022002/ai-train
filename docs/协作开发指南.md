# 协作开发指南

本文说明其他同学如何加入本仓库一起开发（后端 + 网页 + 微信小程序）。

---

## 0. 仓库现状（负责人先做）

当前工程目录若还没有独立 Git 仓库，负责人先完成：

```bash
cd "/path/to/ai-train"
git init
git add .
git commit -m "chore: initial import"
# 在 GitHub / Gitee / 学校 GitLab 新建空仓库后：
git remote add origin <仓库 HTTPS 或 SSH 地址>
git branch -M main
git push -u origin main
```

务必确认 `.gitignore` 已忽略：

- `.env`、`.env.local`（密钥）
- `.venv/`、`node_modules/`、`miniprogram/dist/`

密钥**只通过私聊 / 密码管理器**分发，不要提交、不要发到群文件明文。

## 1. 新人接入（一天内能跑起来）

### 1.1 拿到代码

```bash
git clone <仓库地址> ai-train
cd ai-train
```

### 1.2 后端

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # 再按需填写密钥
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

浏览器打开：http://localhost:8000/docs  

无 LLM 密钥时也可跑通大部分接口（AI 教练会进「本地教练模式」）。

### 1.3 网页前端（可选）

```bash
cd frontend
npm install
# 配置 NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev
```

### 1.4 微信小程序

```bash
cd miniprogram
npm install
npm run dev:weapp
```

1. 打开微信开发者工具 → 导入项目目录 `miniprogram/`（读 `dist/`）
2. 详情 → 本地设置 → 勾选 **不校验合法域名…**
3. 编译；模拟器用 `API_BASE=http://localhost:8000`
4. **真机调试**：手机与电脑需能互通（校园网常有设备隔离 → 用手机热点），然后：

```bash
./scripts/sync-api-base.sh --write
cd miniprogram && npm run build:weapp
```

详见 [`miniprogram/README.md`](../miniprogram/README.md)。

本地默认游客 AppID；需要真机预览/发布时申请正式号，见 **[微信 AppID 申请与接入](微信AppID申请与接入.md)**。

## 2. 推荐分支与提交流程

采用 **主干 `main` + 功能分支 + PR/MR**，不要直接往 `main` 推未审代码。

| 步骤 | 说明 |
|------|------|
| 1 | `git checkout main && git pull` |
| 2 | `git checkout -b feat/短横线描述` 或 `fix/…`、`docs/…` |
| 3 | 本地改完、自测通过 |
| 4 | `git push -u origin HEAD` |
| 5 | 在平台提 Pull Request / Merge Request |
| 6 | 至少 1 人 Review 后合并 |

### 分支命名

- `feat/coach-voice` — 新功能  
- `fix/guide-image-ios` — 修 bug  
- `chore/env-example` — 工具/依赖  
- `docs/collab-guide` — 文档  

### Commit 信息（建议）

```
feat: 小程序教程改为本地下载后播放
fix: 真机 API_BASE 同步脚本
docs: 补充协作开发指南
```

一句话说明「为什么」，避免只写 `update`。

## 3. 模块边界（减少互相踩脚）

| 目录 / 文件 | 负责人关注点 | 注意 |
|-------------|--------------|------|
| `main.py`、`routers/`、`*.py` 后端核心 | API、业务逻辑 | 改接口要同步前端/小程序 |
| `exercise_db.json`、`exercise_meta.py` | 动作库与教程图 | 英文名为 canonical key |
| `frontend/` | Next.js 网页 | 动作中文见 `lib/exercise-labels.ts` |
| `miniprogram/` | Taro 小程序 | 中文映射见 `src/utils/exercise-labels.ts`，**需与网页同步** |
| `.env` | 每人本地 | 勿提交；模板用 `.env.example` |

**动作中文名**：改映射时同时改  

- `frontend/lib/exercise-labels.ts`  
- `miniprogram/src/utils/exercise-labels.ts`  
- （可选）`app.py` 里的 `EXERCISE_CN`

## 4. 环境变量约定

复制 `.env.example` → `.env`，常用项：

| 变量 | 作用 |
|------|------|
| `USE_REAL_LLM` | `true` 才走真实大模型 |
| `LLM_PROVIDER` | 如 `openai`（DeepSeek 也走 OpenAI 兼容） |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` | 对话与计划生成 |
| `WHISPER_API_KEY` 等 | 小程序语音识别兜底（与 DeepSeek 密钥分开） |

LLM 余额不足时接口仍 200，但教练会提示「本地教练模式」——先查账单再查代码。

## 5. 联调与真机

| 场景 | API 地址 |
|------|----------|
| 开发者工具模拟器 | `http://localhost:8000` |
| 真机 | `http://<电脑局域网IP>:8000`，用 `scripts/sync-api-base.sh --write` |
| 后端监听 | 必须 `--host 0.0.0.0` |

真机教程图：小程序会 `downloadFile` 再播放；需勾选不校验合法域名。

## 6. Code Review 清单（合并前）

- [ ] 不包含 `.env`、密钥、本机绝对路径硬编码（文档示例除外）  
- [ ] 新接口有简要说明或更新 `README` / OpenAPI 可自解释  
- [ ] 小程序改动已 `npm run build:weapp` 能通过  
- [ ] 后端相关改动本地 `uvicorn` 能启动；关键路径手测或有测试  
- [ ] 动作名中英文映射若有新增，三处保持同步  

---

## 7. 沟通建议

1. **先开 Issue / 群里认领**，避免两人改同一功能。  
2. 大改动（鉴权、数据库、Tab 结构）先短设计说明再动手。  
3. 卡住时附上：操作系统、是模拟器还是真机、`API_BASE`、后端日志关键几行。  
4. 组会演示：后端 + 小程序真机用热点，避免校园网隔离。  

---

## 8. 最小角色分工示例（可按组调整）

| 角色 | 范围 |
|------|------|
| 后端 | FastAPI、风险引擎、教练 Agent、`.env` 模板 |
| 网页 | `frontend/` 体验与 UI |
| 小程序 | `miniprogram/` 页面、真机联调、教程/语音 |
| 内容 | `exercise_meta` 要领与图、中文名校对 |

每人保持可独立跑通「后端 + 自己负责的客户端」。
